# 个人网站参考调研：视觉、内容组织与长期扩展

调研日期：2026-10-10（Asia/Shanghai）  
阶段：研究与讨论，尚未确定最终设计、栏目名称或技术方案。

## 研究方法与可信度

- 以作者本人网站为一手来源，实读首页和关键内容入口，不使用设计榜单截图代替当前版本。
- 本文的“观察”指页面公开内容或本次浏览器截图中可直接看到的事实；“建议 / 推论”指根据目标作出的设计判断，不代表作者的设计意图。
- 12 个主样本均获得了首页正文；其中 11 个通过浏览器查看了当前首屏。Brian Lovin 在浏览器中遇到验证页，因此仅分析检索工具获得的文本结构，不断言其当前配色、字体或布局。
- 首屏观察是桌面视口的一次快照，不等于已完成移动端、无障碍、动效或性能审计。网页会变更，实施时若借鉴细节应重新查看。
- 所有下列链接均于 2026-10-10 访问。每个网站只借鉴设计思路，不复制其品牌、插画、文案或作品。

## 12 个主样本

### 1. Steph Ango：温和的个人出版物

**观察 — 视觉：** 本次首屏为偏奶油色背景、窄幅居中正文、深色文字和轻分隔线；没有大横幅或图文卡片墙。顶部直接展示姓名、About、Now 和主题切换。

**观察 — 内容：** 首页依次是最新文章、Topics 标签、按时间列出的 Writing。标签涉及设计、学习、习惯、人际关系等；项目链接可由 Now 内部找到，未把所有内容类型都放进顶部导航。[首页](https://stephango.com/)、[Now](https://stephango.com/now)。

**建议 / 推论：** 可借鉴短介绍、轻导航、文字列表和生活 / 工作共存的方式。若希望项目和其他网页成为明显入口，应把它们补在首页，不能完全照搬写作优先的布局。大量标签应进入二级页面，首屏只放有意义的一小组。

### 2. Maggie Appleton：允许想法尚未完成的花园

**观察 — 视觉：** 首屏使用大号衬线标题、浅底、宽留白和少量品红 / 青绿点缀；桌面顶部可见 The Garden 下拉入口、Now、About。工具抽取的所有链接不等于它们全部并排显示在导航中。

**观察 — 内容：** 首页分区呈现 Essays、Notes、Patterns、Library；Garden 聚合页具备 Topics、Growth Stages、Types 三种维度，成长阶段包括 Seedling、Budding、Evergreen。生活与技术内容都在站内。[首页](https://maggieappleton.com/)、[Garden](https://maggieappleton.com/garden)。

**建议 / 推论：** 最值得借鉴的是“短笔记也能发布，并可继续更新”，而非一开始照搬全部栏目。其视觉辨识度也依赖作者长期视觉创作。新站可先借鉴温暖排版和文章 / 笔记区分，成熟度标记作为以后可启用的能力。

### 3. Anthony Fu：把主页写成一封自我介绍

**观察 — 视觉：** 白底、居中窄正文、简洁姓名标题、灰色正文与轻微图标点缀；项目名称以小徽标和轻背景嵌在句子中。顶部文字导航为 Blog、Projects、Talks、Sponsors，并有图标入口。

**观察 — 内容：** 简介串起在做什么、创造 / 维护的项目、文章、演讲、播客、生成艺术、摄影、旅行、设备清单与联系渠道。文章、项目和照片分别有独立入口。[首页](https://antfu.me/)、[Posts](https://antfu.me/posts)、[Projects](https://antfu.me/projects)、[Photos](https://antfu.me/photos)。

**建议 / 推论：** 非常适合“个人网页其他入口”的目标：链接有上下文，比密集链接按钮更有个人性。首页若完全以简历段落为主，新访客不容易看到最近更新；建议再补 3–5 条最新记录和 2–3 个精选项目。

### 4. Derek Sivers：明确、直接、内容丰富

**观察 — 视觉：** 此次首屏为淡桃色背景、衬线正文、明显蓝色下划线链接、窄幅单栏；标题与段落间有大块留白，视觉更接近个人文集。

**观察 — 内容：** 首页先用 10 秒简介和人生阶段介绍，再引导至 About、Now、Contact；之后有文章、书籍、访谈、项目、短动态、照片及分发平台。Now 页面公开标注更新时间。[首页](https://sive.rs/)、[Now](https://sive.rs/now)。

**建议 / 推论：** 可借鉴分层的自我介绍和“现在正在做什么”，减少首次访问理解成本。首页内容规模很大，适合已有长年积累的作者；新站无需预造同样多的区块。视觉可更精致，但应保留其直接可读的语言。

### 5. Lee Robinson：简介、长期主题与文章分开

**观察 — 视觉：** 当前首屏是白底，左侧衬线文字介绍和 Notes，右侧大幅彩色城市插画；顶部以 @leerob 为标识。Bio 有 Default / Long 两种长度按钮。它不是网络中常见的旧版技术作品集界面。

**观察 — 内容：** 当前首页分为 Bio、Notes、Blogs。Notes 以主题页组织观点，Blogs 展示带月份的文章列表。首页不是按多层菜单组织内容。[当前首页](https://leerob.com/)。

**建议 / 推论：** 对“想法”很有帮助：稳定观点可以是一张持续维护的主题页，而不必每次都写一篇新文章。右侧插画可带来个性，但需要匹配个人经历的原创视觉。项目和生活入口需另行增加。

### 6. Brittany Chiang：职业作品集的边界样本

**观察 — 视觉：** 桌面首屏为深蓝底、浅文字、左右两栏；左侧姓名、职位、定位语和 About / Experience / Projects 锚点导航，右侧是介绍与经历内容。其布局明显突出专业身份。

**观察 — 内容：** 主体含 About、Experience、Projects、Writing；项目带描述和技术标签，并链接完整项目档案；Writing 中有指向站外文章的入口。[首页](https://brittanychiang.com/)。

**建议 / 推论：** 可借鉴项目呈现和深色视觉，但它偏职业作品集。生活、随笔和长期记录若成为本站的重要内容，应加入独立阅读结构，避免所有内容塞进一个长作品集页。示例中专业履历的权重不宜直接移植。

### 7. Manuel Moreale：直接进入生活与写作

**观察 — 视觉：** 本次根地址直接进入最新文章。白底、衬线标题与正文、窄幅阅读区、大留白，照片可使用比正文更宽的展示区域；首屏没有复杂导航。

**观察 — 内容：** 当前根地址跳转至一篇户外生活文章，正文后有 newsletter / RSS 入口，再接按年月组织的历史文章；末尾链接 Now、Blogroll、About。档案中可见生活、阅读、网页文化和技术相关内容。[根入口](https://manuelmoreale.com/)、[本次进入的文章](https://manuelmoreale.com/fromthesummit/beginning-at-the-end)。

**建议 / 推论：** 适合解释“网站可以先是一种持续写作习惯”。对希望初访者理解个人定位和项目的本站，更适合借鉴文章页阅读体验，不建议直接复制根地址进入最新文章的做法。

### 8. Paco Coursey：有作品也可以保持安静

**观察 — 视觉：** 白底、留白充足、灰黑文字、少量下划线链接。介绍下方在桌面视口分成 Building、Projects、Writing 三个小栏；没有厚重卡片和大图。

**观察 — 内容：** 首页包含 Building、Projects、Writing、Now、Connect。项目和文章都给简短解释，Now 还包含个人兴趣和音乐链接。[首页](https://paco.me/)。

**建议 / 推论：** 可以借鉴模块很小、描述很短的首页，让“个人介绍 + 内容入口 + 项目”在不拥挤的情况下共存。文字项目适合数量少的阶段；需要展现项目细节时，进入二级页再使用截图和完整案例。

### 9. Brian Lovin：个人工具与兴趣入口的集合

**观察 — 文本结构：** 首页有头像 / 姓名、短介绍、Writing 和 Projects。Projects 不限职业作品，还包括应用拆解、工具清单、AMA、TIL、音乐、网站收藏、阅读工具及站外项目。[首页](https://brianlovin.com/)、[网站收藏](https://brianlovin.com/sites)。

**视觉核实限制：** 浏览器首屏为验证状态，未获得正常页面截图。本节不以记忆判断其配色、布局或交互动效。

**建议 / 推论：** 很适合借鉴“一个总入口连接个人在互联网上的各种地方”。不必把这些链接都叫项目，可建立“我的其他入口”模块，用用途和说明帮助读者理解。兴趣模块也能承载个人辨识度。

### 10. Tania Rascia：内容多了以后如何仍然容易逛

**观察 — 视觉：** 此次首屏为奶油浅底、左侧轻导航栏、右侧主体内容、品红强调色，辅以少量像素风图标和一只角色插画。主区先展示个人经历时间线。

**观察 — 内容：** 主导航含 Blog、Shelves、Projects、About me；还有 Topics。首页 Shelves 是手选内容路径，Series 是多篇连续内容，项目提供 Article / Demo / Source 等入口。[首页](https://www.taniarascia.com/)。Shelves 子页的本次后续抓取超时，因此合集判断以已成功读取的首页为准。

**建议 / 推论：** 借鉴“精选合集不等于主题标签、专栏也不等于合集”的划分，适合未来长内容库。新站不需要立刻展开所有层级；先保存这些关系，积累后再决定哪些合集值得成为导航入口。

### 11. pseudoyu：中文生活记录与独立项目共存

**观察 — 视觉：** 首页与 Anthony Fu 的结构接近：白底、轻图标导航、窄正文、自我介绍和项目徽标；本次首屏能看到 Blog、Projects、Talks、Media、Sponsors、Let's Chat。

**观察 — 内容：** 首页介绍为英语，但 Posts 有中文周报、感情 / 婚礼、旅行、搬家、创作、技术和年末回顾。项目页分组呈现当前关注、AI 产品、设计、网站、应用等；Media 用书、电影、剧集、动画、游戏来组织兴趣。[首页](https://www.pseudoyu.com/)、[Posts](https://www.pseudoyu.com/posts)、[Projects](https://www.pseudoyu.com/projects)、[Media](https://www.pseudoyu.com/media)。

**建议 / 推论：** 对本站很适合：先用周记或不定期近况串起生活与项目，再从自然积累的内容中生长出专栏。栏目不需要先分成大量互斥主题。频率是形式选择，无需因为叫周报而给自己强制每周更新。

### 12. Limboy：轻记录是一种完整的网站内容

**观察 — 视觉：** 白底、窄单栏、轻边框分隔；顶部仅存档、音乐、相册、关于。下方是近况 / 想法 / 图集组成的时间流；图集在有限宽度内横向显示多张照片。

**观察 — 内容：** 首页混合项目进展、生活照片、短想法、周记及站外长内容链接；部分动态实际指向 before.town。存档页按年呈现站内文章，涵盖技术、习惯、生活和作品。[首页](https://limboy.me/)、[存档](https://limboy.me/archive)、[相册](https://limboy.me/photos)。

**建议 / 推论：** 可借鉴“可以只发一句话或一张照片”，降低持续更新门槛。对建立个人 IP 的初访者，应在时间流前增加一句定位和精选项目，避免近期碎片淹没长期代表作。不要假设所有动态天然都需要第三方同步；发布方式应以后单独确定。

## 共通结构：哪些可以先简单，哪些需要留弹性

以下是基于上述样本的归纳，不是对所有个人网站的统计结论。

1. **身份信息通常很短。** 一个名字、一句介绍、在做什么，就足以让人建立初步认识。案例：Anthony Fu、Paco、Brian、pseudoyu。
2. **精选与最新解决不同问题。** 最新让人感知持续更新；精选让初访者迅速知道最值得看什么。不能仅凭时间排序决定个人形象。案例：首页最新列表与内容策展并存的 Tania。
3. **生活内容可以和专业内容共存。** Anthony 的摄影、pseudoyu 的周报、Limboy 的时间流都提供实际例子。无需将人生先切成十几个互斥栏目。
4. **总导航可以少，二级内容可以丰富。** Maggie 将更多内容放在 Garden 内；Steph 的项目可由 Now 到达。分类多少不等于导航多少。
5. **“现在”是独立于履历的入口。** Steph、Derek、Paco 都公开描述当前在做什么，比一直修改长篇 About 更容易表达变化。
6. **外部入口最好有上下文。** 一个链接说明是项目体验、摄影集还是联系渠道，比一排无法辨认的图标更能帮助新访客。

## 建议讨论的组合，而非最终栏目承诺

推荐基础组合：**Steph 的阅读与留白 + Anthony / Paco 的个人入口 + pseudoyu / Limboy 的日常记录 + Tania 的后续策展能力**。如果更喜欢带有文学和插画气质的首页，可把 Maggie / Lee 的视觉语言作为替代方向。

### 一层稳定入口

可先讨论四至五个入口：**首页、记录、项目、关于、更多**。名字均待用户确认，“更多”可以是下拉菜单或页尾，不必强制成为一级页。

- 首页：一句个人介绍、最近在做什么、精选记录、精选项目、其他网页入口。
- 记录：统一入口容纳文章、短想法、生活图文；读者可按类型或标签筛选。
- 项目：作品说明和体验 / 源码 / 相关文章入口；可包含小实验。
- 关于：个人故事、长期兴趣和联系入口。
- 更多：未来可放相册、书影音、工具箱、友情链接、RSS 等，已有内容再显示。

### 不应混成一棵分类树的维度

| 维度 | 回答什么 | 可用例子 | 能否后加 |
|---|---|---|---|
| 内容类型 | 这是什么形式？ | 长文、短想法、照片 / 图文 | 应支持新增 |
| 主题标签 | 它在谈什么？ | 生活、设计、AI、阅读 | 可自由增加、修改 |
| 专栏 / 系列 | 它是否属于连续内容？ | 月记、项目日志、读书笔记 | 有内容后创建 |
| 精选合集 | 想带读者怎样阅读？ | 初次来访推荐、关于创造力的五篇文章 | 可随时策展 |
| 更新状态 | 这是不是仍在发展？ | 笔记、持续更新 | 可先不在界面显示 |

这是建议的数据与编辑弹性，不是已经决定需要同时上线的五套筛选器。比如一篇“杭州散步时想到的产品设计”可以同时有生活和设计标签；它仍只有一个原始内容地址，也可以被加入未来的散步合集。

### 首页与阅读页的视觉边界

- 首页可宽一点，方便介绍与项目；文章正文应保持舒适行宽。
- 色彩可以克制，但个人标识必须清楚：一个强调色、稳定排版和可辨认的头像 / 标志即可。
- 图片应对内容有帮助；没有好图片的文章仍应显得完整，不要求所有记录配封面。
- 英文站的衬线字体效果不等于中文效果；中文阅读字体、字号、行距和标题效果需在后续 demo 中用真实中文确认。
- 动效是可选的表达细节，不应成为首页必须等待才能阅读的前提。此次截图不足以对各站动效性能作判断。

## 补充样本与不可用候选

- [Josh W. Comeau](https://www.joshwcomeau.com/)：已核实内容主要是文章 / 教程、分类、课程与 goodies，适合进一步研究教学内容和互动文章。本项目并非以教程为中心，未列入 12 个主样本；没有本次视觉核实。
- [Austin Kleon](https://austinkleon.com/)：已核实博客时间流、Books、Newsletter、Speaking、About、Contact，且生活和创作内容共存。适合作者型网站与订阅参考；没有本次视觉核实。
- [yufan.me](https://yufan.me/)：本次跳转至 `/admin/setup` 并要求 Setup Token，无法作为已核实的正常公开设计样本。没有尝试管理功能，也不据此判断作者网站长期状态。

## 后续需要用户确认的点

1. 视觉更偏温暖文集、清爽个人主页、还是深色作品集？
2. 初访者应先记住什么：生活观察、专业能力、创作项目，或同等权重？
3. 记录是否要同时允许长文、短想法和照片？
4. 是否需要单独的“现在在做什么”，还是放首页一块即可？
5. 其他网页入口有哪些已存在的真实链接，哪些属于以后计划？
6. 后续更希望通过网页后台、Markdown 文件或现有笔记工具更新？此项会影响实施方式，研究阶段暂不做技术承诺。

补充确认（2026-10-10）：用户已明确选择“兼顾个人表达与项目展示”及“在本地写 Markdown 文件，再发布”。其余问题仍待讨论。所有确认与最新方案状态，以 [设计讨论与确认记录](../personal-website-design-brief.md) 为准。
